How the Modules Connect: Module 1 operates as a standalone computer-vision inspection pipeline that detects 6 classes of bare-board fabrication defects using Faster R-CNN. Modules 2, 3, and 4 form a sequential engineering and supply-chain pipeline: Module 2 parses and cross-validates the BOM (bom.csv) and KiCad netlist (board.net) to extract each component's footprint and pin-to-net connectivity; Module 3 consumes a selected component's footprint and pinout from Module 2 alongside operating requirements to filter catalog MOSFETs by package, pinout, and electrical limits with datasheet evidence; and Module 4 takes the eligible candidates from Module 3 and ranks them across timestamped supplier quotes by normalized price, stock, and electrical trade-offs. All four modules are served together through a unified FastAPI backend and Streamlit UI.
